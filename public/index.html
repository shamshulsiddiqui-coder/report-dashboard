⚙️ Parameters

📖 Definitions & Formula Reference

Click to expand / collapse
⚙️ Input Parameters
AHT Average Handle Time — total time an agent spends per call.
AHT = Talk Time + ACW (After Call Work)
Auto-calculated from your actual sheet data.
SL Target % Service Level target — what % of incoming calls should be answered within the threshold time. Industry standard: 80%.
Answer in (sec) The time threshold for SL. "80% in 20 sec" means 80% of calls must be answered within 20 seconds. Common targets: 20s, 30s, 60s.
Shrinkage % Time agents are unavailable to take calls — includes breaks, lunch, training, meetings, leave, bathroom, etc.
Typical: 25–35%. Higher shrinkage = more headcount needed.
Interval Time block for grouping calls. 30-min is industry standard for intraday planning. Shorter interval = more granular staffing plan.
📊 Output Table Columns
Avg Calls Average calls received in that time slot across all selected days. This is the call volume used for planning.
Calls/Hour Calls extrapolated to hourly rate.
= Avg Calls × (60 ÷ Interval minutes)
Traffic (A) Erlang traffic intensity — amount of work arriving per unit time.
A = (Calls/Hour × AHT) ÷ 3600
E.g., A=2.5 means agents carry 2.5 hrs of work per hour.
Min Agents Minimum concurrent agents calculated by Erlang C formula to achieve your SL target. This is the "on-phone" requirement.
Reqd (w/ Shrinkage) Final headcount after adjusting for unavailability.
= Min Agents ÷ (1 − Shrinkage%)
This is your actual roster count needed.
SL % Estimated service level achieved with Min Agents. Green = at/above target, Yellow = within 10% of target, Red = below target.
ASA (sec) Average Speed of Answer — expected average wait time for callers before being connected to an agent.
Occupancy % % of time agents are actively handling calls.
= Traffic (A) ÷ Min Agents × 100
<80% = healthy, 80–90% = caution, >90% = overloaded.
Erlang C Model: Assumes calls arrive randomly (Poisson distribution), agents handle one call at a time, waiting callers do not abandon. It calculates the minimum agents where the probability of waiting × expected wait time meets your SL target. Real-world results may vary due to call abandonment and non-uniform arrival patterns.
